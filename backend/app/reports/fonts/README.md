# Report fonts

Bundled so the PDF looks the same on every server, and because a server rarely has a
Sinhala font installed. All three are under the SIL Open Font License 1.1 (the `OFL-*.txt`
files beside them), which allows bundling and embedding.

| File | Family | Source |
|---|---|---|
| `NotoSansSinhala-Regular.ttf`, `NotoSansSinhala-SemiBold.ttf` | Noto Sans Sinhala | Google Fonts, through the `@expo-google-fonts/noto-sans-sinhala` npm package |
| `DMSans-Regular.ttf`, `DMSans-Medium.ttf`, `DMSans-SemiBold.ttf` | DM Sans | `@expo-google-fonts/dm-sans` |
| `Marcellus-Regular.ttf` | Marcellus | `@expo-google-fonts/marcellus` |

These are the same families the website uses.
